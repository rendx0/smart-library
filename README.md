# Smart Library - Ухаалаг Номын Сан 📚

Орчин үеийн, ухаалаг номын сангийн вэбсайт. Сургуулийн оюутан, багш, эцэг эхчүүдэд зориулсан цэвэрхэн, минимал дизайнтай платформ.

## ✨ Онцлог

- 🎨 **Glassmorphism & Neumorphism** дизайн элементүүд
- 🔵 **Цэнхэр болон цагаан** өнгийн гөлгөр хослолт
- 📱 **Төлөвлөгөө оруулсан дизайн** - мобайл, таблет, компьютер
- ⚡ **Гөлгөр анимейшнууд** - орчин үеийн ощущение
- 🔍 **Хүчирхэг хайлтын систем**
- 📊 **Номын сангийн статистик**
- 🎯 **Ашиглахад хялбар интерфэйс**

### Установка

1. **Репозиторийг клон хийх:**
```bash
git clone https://github.com/rendx0/smart-library.git
cd smart-library
```

2. **Вебсайтыг нээх:**
```bash
# index.html файлыг хөтөчөөр нээнэ үү
# эсвэл
python -m http.server 8000
# дараа нь http://localhost:8000 руу ордоо
```

## 🎨 Дизайн Элементүүд

### Цвет Палет
- **Үндсэн**: #0066cc (Цэнхэр)
- **Хоёрдогч**: #00a8ff (Анги цэнхэр)
- **Энергийн өнгө**: #ff6b6b (Улаан)
- **Фон**: #f8f9ff (Ялбар цагаан)
- **Текст**: #1a1a2e (Хар)

### Дизайн Загварууд
- **Glassmorphism**: Мөрлөгт материал нөлөөлөлтэй картууд
- **Neumorphism**: Мэдрэгчтэй нэрмэл сүүдэр
- **Дугуй булан**: 15-20px border-radius
- **Гөлгөр сүүдэр**: Гадаад гэмтэлгүй нөлөөлөл

## ⚙️ Функционалын Код

### JavaScript Функцүүд

#### `performSearch()`
Номын хайлт, шүүлтүүр сонголт

#### `initializeCarousel()`
Шинээр ирсэн номуудын каруусель удирдлага

#### `showNotification(message, type)`
Сүүлийн харуулалт мэдэгдэл

#### `initializeFormValidation()`
Контакт хэлбэрийн баталгаажуулалт

#### `updateActiveNavLink()`
Идэвхтэй навигационн холбоос шинэчлэл

## 📱 Төлөвлөгөө оруулсан Дизайн

### Desktop (1200px+)
- Сүлжээний байршил
- Бүтэн өргөний контент
- 3 баганатай сүлжээ

### Таблет (768px - 1199px)

### Мобайл (480px - 767px)

- Жижиг элементүүд
- Минимал padding
